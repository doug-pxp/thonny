Softsembly v0.4 — Zero-Setup Python

Changes:
- Softsembly's own runtime is the default Python for user programs.
- Fresh users do not need to select or install a Python interpreter.
- First-run screen is simplified to language selection plus a ready message.
- Status bar shows “Softsembly Python” instead of a technical interpreter path when using the default runtime.
- Advanced interpreter selection remains available in Options.
- No toolbar, debugger, menu, file-browser, lesson, cartridge, package-name, or packaging redesign in this revision.
