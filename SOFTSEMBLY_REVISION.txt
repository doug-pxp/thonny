Softsembly v0.6c

Milestone: Windows path handling + external Python-file drag and drop.

Changes from v0.6b:
- Raw Windows paths like D:\\_PXP\\... are recognized as filesystem paths before URI parsing.
- UNC paths remain supported.
- Dragging .py or .pyw files from Windows Explorer or macOS Finder onto the editor opens them.
- Adds tkinterdnd2 as a runtime dependency for cross-platform native file drops.
- Drag-and-drop failure never blocks Softsembly startup.

No UI redesign or workflow changes.
