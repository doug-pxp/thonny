Softsembly v0.5 — Windows Installer Packaging

Changes:
- Adds a one-command Windows installer build flow.
- Packages a private Python 3.14 runtime with Softsembly.
- Installs the current local Softsembly source instead of pulling Thonny from PyPI.
- Creates a Softsembly.exe launcher and Softsembly-branded shortcuts/file associations.
- Keeps user settings separate from upstream Thonny under a Softsembly profile directory.
- Makes BasedPyright discoverable from the bundled Python Scripts directory.
- Keeps all v0.3f UI behavior and v0.4 zero-setup Python behavior.
- Installer is intentionally unsigned in v0.5; code signing is a later release hardening step.
